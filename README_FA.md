# ایجنت خبری کوین فا نیوز

**روند کار:** سایت‌های خبری رمزارز ← انتخاب ۵ خبر مهم روز ← بازنویسی فارسی و انسانی + تیتر + کپشن + کلیدواژه + هشتگ
← ساخت تصویر با قالب کوین فا (لوگو و تیتر بالا، عکس مرتبط پایین) ← ارسال به تلگرام شما با دکمه‌ی ✅ / ❌
← با زدن ✅، پست روی اینستاگرام منتشر می‌شود.

ربات هر وقت کامپیوتر روشن باشد کار می‌کند. هر ۳۰ دقیقه چک می‌کند و اگر سهم امروز (۵ خبر) هنوز کامل نشده باشد، بقیه را می‌سازد.

---

## ۱) پیش‌نیاز
- Python نسخه‌ی 3.10 یا بالاتر (python.org). در ویندوز موقع نصب تیک **Add to PATH** را بزنید.

## ۲) کلیدهایی که لازم دارید (همه را خودتان در فایل `.env` بگذارید)

| کلید | از کجا | هزینه |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com ← API Keys | چند سنت در روز |
| `TELEGRAM_BOT_TOKEN` | در تلگرام به **@BotFather** پیام بدهید ← `/newbot` | رایگان |
| `TELEGRAM_CHAT_ID` | به **@userinfobot** پیام بدهید؛ عدد Id را بردارید | رایگان |
| `PIXABAY_API_KEY` (اختیاری) | pixabay.com/api/docs — اگر نباشد، عکس‌ها بدون کلید از Openverse می‌آیند | رایگان |
| `IMGBB_API_KEY` | api.imgbb.com (برای لینک عمومی موقت عکس که اینستاگرام لازم دارد) | رایگان |
| `IG_USER_ID` و `IG_ACCESS_TOKEN` | مرحله‌ی ۳ | رایگان |

⚠️ بعد از ساخت ربات، یک‌بار خودتان به ربات‌تان `/start` بدهید؛ وگرنه ربات نمی‌تواند به شما پیام بدهد.

## ۳) گرفتن دسترسی انتشار اینستاگرام (یک‌بار)
1. حساب اینستاگرام باید **Professional** باشد (Creator یا Business).
2. به developers.facebook.com بروید ← **Create App** ← کاربرد مربوط به **Instagram** را انتخاب کنید
   (گزینه‌ی *Instagram API with Instagram Login*).
3. در بخش **API setup with Instagram login** ← **Generate access tokens** ← حساب @coinfanews را اضافه و تأیید کنید.
   مجوزهای `instagram_business_basic` و `instagram_business_content_publish` لازم است.
4. توکن ساخته‌شده را در `IG_ACCESS_TOKEN` و شناسه‌ی عددی حساب را در `IG_USER_ID` بگذارید.
   توکن ۶۰ روز اعتبار دارد و خود ربات هر ۵۰ روز آن را تمدید می‌کند (به شرطی که در این فاصله حداقل یک‌بار روشن شده باشد).

> نام دکمه‌ها در پنل متا گاهی کمی عوض می‌شود؛ مسیر کلی همین است.

## ۴) راه‌اندازی
1. فایل `.env.example` را کپی کنید و اسمش را `.env` بگذارید، بعد کلیدها را پر کنید.
2. **تست بدون انتشار:** در پوشه‌ی برنامه:
   ```
   py -3 -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   .venv\Scripts\python main.py --dry
   ```
   یک تصویر و متن نمونه در `data/out/` ساخته می‌شود (فقط کلید Claude لازم است؛ با کلید Pixabay عکس واقعی هم می‌گذارد).
3. **اجرای اصلی:** روی `run_windows.bat` دوبار کلیک کنید (در مک/لینوکس: `./run_mac_linux.sh`).

### اجرای خودکار با روشن شدن کامپیوتر (ویندوز)
`Win + R` ← `shell:startup` ← یک **Shortcut** از `run_windows.bat` در این پوشه بگذارید.

## ۵) نکته‌های مهم
- **سهم روزانه:** ۵ پیش‌نویس در روز (`DAILY_POSTS` در `.env`). خبرهای تکراری هیچ‌وقت دوباره نمی‌آیند.
- **دکمه‌ها وقتی کامپیوتر خاموش است:** پیش‌نویس‌ها ذخیره می‌مانند، ولی تلگرام کلیک‌ها را فقط **۲۴ ساعت** نگه می‌دارد.
  یعنی اگر ✅ را زدید و کامپیوتر تا فردا روشن نشد، دوباره بزنید.
- **اگر انتشار خطا داد،** دکمه‌ها باقی می‌مانند تا دوباره امتحان کنید. جزئیات در `data/agent.log` است.
- **عکس‌ها** از Openverse (بدون کلید؛ فقط عکس‌های آزاد CC0 و CC BY، با ذکر نام عکاس در کپشن) یا در صورت داشتن کلید از Pixabay می‌آیند، نه از سایت خبری؛ تا پیج به‌خاطر کپی‌رایت گزارش نخورد.
  اگر عکسی پیدا نشود، پس‌زمینه‌ی تیره‌ی ساده گذاشته می‌شود.
- **لحن متن** طبق بازخوردهای قبلی تنظیم شده: نیم‌فاصله‌ی درست، بدون سیگنال خرید و کلمات زرد، ذکر منبع،
  هشتگ‌های درست و هشتگ برند ثابت. برای تغییر لحن، متن `SYSTEM_WRITER` در `coinfa/writer.py` را ویرایش کنید.
- **منابع خبر** در `coinfa/config.py` (لیست `FEEDS`) قابل تغییرند.
- فایل `.env` شامل کلیدهای شماست؛ آن را با کسی به اشتراک نگذارید.
